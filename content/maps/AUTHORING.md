# 地圖製作指南

每張地圖是 `content/maps/<id>.json` 一個檔案。改完存檔後執行 `npm run validate-maps`，
沒有 `[FAIL]` 才算合法。開發伺服器執行中時，前端會自動重新載入。

## 1. 檔案結構

```json
{
  "id": "maze-01",                       // 檔名與 id 一致，網址用 ?map=maze-01 選它
  "name": "Maze 01",
  "supportedParticipants": [2, 3, 4, 5, 6],   // 這張圖允許的參賽人數
  "plazaRadius": 1,                      // 塔周圍幾格內豁免「走道一格寬」規則
  "lightSwitchCount": 4,                 // 每局放幾個開關：偶數、至少 2
  "rows": [ "#####...", ... ]            // 版面，每行一個字串，長度一致；候選點直接畫在裡面
}
```

候選點通常直接用字母畫在 `rows` 裡（見第 2、5 節）。若真的需要，也可以另外用座標列表
`"spawns": { "keys": [ { "x": 1, "y": 1, "layer": "road" } ], ... }`，兩種可混用。

## 2. 座標與字元

- `rows[y][x]`：x 向右、y 向下，左上角是 (0,0)。第一行是 y=0。
- `layer` 只有 `road`（地面）與 `wallTop`（牆頂）。

| 字元 | 意義 |
| --- | --- |
| `#` | 牆，一格厚一格高，牆頂可走 |
| `.` | 道路 |
| `S` | 樓梯：地面與牆頂之間唯一的換層點 |
| `=` | 橋：牆頂走道跨過一格道路，道路照常通行 |
| `T` | 中心塔占地（塔本身會依 T 的範圍自動畫出） |
| `X` | 空白，任何人都不能進入；正式地圖不用 |

候選點標記，載入時會自動換成座標並還原成底下的格子：

| 字元 | 意義 |
| --- | --- |
| `K` | 道路上的鑰匙候選（底下是 `.`） |
| `k` | 牆頂上的鑰匙候選（底下是 `#`） |
| `B` / `b` | 道具箱候選，道路 / 牆頂 |
| `L` | 電燈開關候選，只能在道路上，且四鄰至少一面牆（面板會掛在那面牆上） |

## 3. 版面規則（驗證器會檢查）

1. 最外圈一律 `#`。
2. 走道一格寬、牆一格厚：任何 2×2 不能全是地面可走格，也不能全是牆頂可走格。
   塔周圍 `plazaRadius` 格內例外。
3. 樓梯 `S`：四鄰中恰好一格是 `#`（樓梯往那面升上去），對面那格必須是 `.`，左右不能是另一個 `S`。
4. 橋 `=`：相對的兩側都是 `#`，另外兩側是道路（`.`、`S` 或 `=`）。
5. 所有 `.` 與 `S` 都必須能從塔旁走到；牆頂不要求可達，但放在牆頂的候選點必須能經樓梯走到。
6. 塔要有相鄰的道路格，那些格子是出生點也是登塔入口。

## 4. 奇偶格子法（建議畫法）

1. 寬與高取奇數，例如 21×15。
2. 奇數座標 (奇, 奇) 是路口，一律 `.`；(偶, 偶) 是柱子，一律 `#`；其餘偶數格是路口之間的「通道或牆」。
3. 先把所有通道格填 `#`，再把想打通的通道格改成 `.`。這樣走道必定一格寬、牆必定一格厚。
4. 樓梯放在「三面通、一面牆」的路口（T 字路口），會往那面牆升上去。
5. 橋放在兩側都是柱子的通道格上（把 `.` 改成 `=`），牆頂就能跨過這條路。
6. 想把牆頂路網切開，就讓某根柱子四面都是通道，它會變成孤立柱子。

## 5. 候選點怎麼填

直接在 `rows` 裡把該格改成標記字母即可，不必算座標。例如 `#K.B.L..#` 這一行就在
x=1 放鑰匙候選、x=3 放道具箱候選、x=5 放開關候選。牆頂候選用小寫寫在牆上，例如
`###k###` 表示這段牆的第 4 格牆頂可以生鑰匙。

三種都是「候選」，每局依種子抽出需要的數量：

| 列表 | 每局抽幾個 | 至少要列幾個 |
| --- | --- | --- |
| `keys` | 參賽者數 × 每人鑰匙數（目前 1） | 最大支援人數 |
| `itemBoxes` | 參賽者數 × 每人箱數（目前 2）；補箱也從空著的候選抽 | 最大支援人數 × 2 再加 2 個備用，建議多列一些讓補箱有位置 |
| `lightSwitches` | `lightSwitchCount` | `lightSwitchCount`，建議多列讓每局位置不同 |

限制：一格只能有一種標記；不能放在塔入口格（塔四周的道路格）；牆頂候選要能經樓梯走到。
開關 `L` 只能放在道路上，而且旁邊要有牆；十字路口中央不行。面板會自動掛在北牆，沒有北牆
就依東、西、南的順序找。

另一個要留意的點：玩家放置道具時不能放在任何候選格上。候選點畫得太密會讓走道幾乎沒地方放
道具，建議一條走道上留些沒有標記的格子。
橋面上的候選無法用字母表示，需要時改用座標列表並寫 `"layer": "wallTop"`。

## 6. 全局數字在哪裡

每人鑰匙數、每人道具箱數、開關數下限、回合時間、分數等在
`packages/sim/src/tuning/defaults.ts`，改數字即可。地圖檔只放「這張圖」的東西。

## 7. 預覽

```
http://localhost:5173/?map=maze-01&players=6&seed=1&rot=0
```

- `map`：地圖 id。放進 `content/maps/` 的檔案都會自動列入。
- `players`：假裝幾人（其他人是不動的 CPU），鑰匙與道具箱數量會跟正式對局一樣。
- `seed`：固定抽選結果；換數字看不同抽法。
- `rot`：0～3，順時針轉 90 度的次數。正式對局會隨機抽方向，四個方向都要順眼。

## 8. 驗證訊息對照

| 訊息 | 意思 |
| --- | --- |
| `corridor wider than one tile at (x,y)-(x+1,y+1)` | 那個 2×2 全是地面，補一格牆 |
| `wall thicker than one tile at ...` | 那個 2×2 全是牆頂可走格，打通一格 |
| `stairs at (x,y) must have exactly one adjacent wall` | 樓梯旁的牆不是剛好一面 |
| `stairs at (x,y) must have road opposite its wall` | 樓梯背面不是道路 |
| `bridge at (x,y) must join two walls with road passing underneath` | 橋兩側不是牆、或底下不是路 |
| `road cell (x,y) is unreachable from the tower` | 有封死的區域 |
| `only N keys spawns but M may be needed` | 候選太少 |
| `keys spawn 3,2,wallTop collides with itemBoxes spawn` | 兩個列表用了同一格 |
| `... sits on a tower entry tile` | 候選放到塔入口格 |
| `lightSwitchCount 3 must be even` / `below the minimum` | 開關數要偶數且至少 2 |
| `light switch 5,3,road touches no wall to hang on` | 開關格旁邊沒有牆 |
| `light switch ... must be on the road layer` | 開關不能放牆頂 |
